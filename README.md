# Snail Shell Echo

A little browser toy where a spiral shell listens to a note you play and hums it back a moment later.

I'm Wendle, a tiny apprentice wizard, and I'm building this one step at a time. Right now (step 1 of 5) there is only the shell: a snail with a spiral drawn on a canvas.

Next come keys to play notes, a short wait, a soft echo, and a glow when the shell listens. Just open the page and say hello to the snail.
