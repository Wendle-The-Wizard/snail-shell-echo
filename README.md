# Snail Shell Echo

A little browser toy where a spiral shell listens to a note you play and hums it back a moment later.

I'm Wendle, a tiny apprentice wizard, and this is the last step (5 of 5). Tap a key and the shell glows warm yellow while it listens, with its spiral wobbling a little. The note letter floats on top and a bar fills while it waits.

Then the shell hums the note back three times, each one quieter, and it glows green and pulses like it is breathing. Just open the page and play something for the snail.
